# 一个 UUID 引发的每秒 85 次重画：用 SwiftUI 画一枚会呼吸的磁盘环形图

> 2026-10 · DiskWise 深度文章 · [English version](./ring-en.md)（后续补）

我做了一个开源的 Mac 磁盘清理器 [DiskWise](../..)，它的招牌画面是一枚环形图：整块磁盘画成一圈，扫描时光带绕环推进，每一段弧都是本次实测到的字节。这篇文章讲这枚环背后的五个实现决定——每一个都是踩过坑才定下来的，代码全部开源（Apache-2.0）。

## 先定三条铁律

画之前先想清楚环形图在这类产品里要回答什么。我们定了三条：

1. **一整圈 = 整块盘**。任何一帧，各段之和都等于整盘——包括扫描进行中。做不到这一点，环就是装饰画。
2. **彩色只给动得了的弧**。六色数据系列铺满一圈，读出来是「这盘被六样东西吃掉了」；但这一屏要回答的只有一件事——**哪儿能腾出手来**。颜色给多了，答案就没了。于是弧只分四档：能整个搬走的主色打满（`hot`）；系统随时能腾、本工具不动手的洗成很淡（`washed`）；动不了的一律中性灰（`neutral`）；已经进废纸篓还没让位的主色加虚线（`moved`）。
3. **每段直接标注数值，不靠颜色单独传达**。颜色是无障碍的敌人，旁边的账目行就是兜底。

## 各行之和必须等于圆心：连四舍五入都会说谎

环心写着一个总数，右边账目一行行列着各段。听起来各行四舍五入一下就行？实测翻车：12.0 + 6.3 + 4.2 = 22.5，而圆心写 22.4。每行独立取整，各自往上飘零点几，加起来就不再等于总数——而「分段之和等于整盘」是我们对用户的承诺。

解法是把取整上提到 Core 层一次性分配（`addableHuman`）：先算好每一行该显示的字符串，保证这一列相加正好等于圆心那个数，UI 层不许自己 `human()`。

还有一条派生纪律：`reclaim == 0` 的弧上不许画那道「点我」的亮沿。**画了收不走，那一格就是在骗人点击。**

## 最贵的教训：一个 UUID 引发的每秒 85 次重画

环形图的数据段叫 `GaugeSegment`。第一版很自然地给它 `Identifiable`，id 用 `UUID()`——灾难的开始。

SwiftUI 每次 `body` 求值都会重新构造这份段数组，UUID 每次都是新的，于是 SwiftUI 把整列账目行当成「全换了一批新行」拆掉重挂。重挂意味着六行的鼠标跟踪区跟着重注册，AppKit 对着**根本没动过的**光标再放一次 exit + enter，`hovKey` 被写两次，触发整页重画——重画又构造新的 UUID——自激环。

真鼠标静止状态下实测：**每秒 85 次整页重画、730 次悬停事件**。

解法朴素到不好意思：段不做 `Identifiable`，行的身份由使用方按位置给（`ForEach(..., id: \.offset)`）。悬停状态归页面持有而不归环持有——环和右边那列账目读的是同一个 `hov`，两边各记一份就会出现「弧亮了、行没亮」。

## 光的三个来源

环上有三种光，驱动方式各不相同：

**入场光束**走 `TimelineView`，只在头一秒存在，走完就把常驻反光交出来——否则这一屏留下的是一张没有光带的环。

**扫描光束**钉在进度上：`scanProgress` 是 0…1 的实测进度，光束的角位置直接由它决定。它一亮着就说明这一圈还没量完——用户不需要读进度条，光带停在哪，就量到哪。

**常驻反光**最容易写错：直觉是用 `TimelineView` 每帧算角度，那意味着这块屏永远没有静帧。我们没有这样做，而是交给 Core Animation 做一次 0→360° 的线性 `repeatForever`——SwiftUI 视图树完全静止，光在走。

为什么「静帧」这么重要？因为测试链依赖它：截图模式靠**比对连续三帧**判定画面稳定（`waitSettled`），永续动画会让每张总览图都拖到超时上限。`accessibilityReduceMotion` 下不转、不呼吸。

## 灯不是主色：HSB 校正

最后一个细节：发光用哪个颜色？直觉拿主题色直接当灯——错。极夜皮肤的主色 #C9A227，蓝色通道只有 39，直接当灯用，光透到灰弧上就是芥末色而不是金色。解法是转 HSB 只动饱和与明度、色相不碰，六套皮肤各发自己那道光，各自都成立。

环带厚度也有讲究：原型外径 412、带 56，比例 0.136。取厚了内孔只剩 0.66 框宽，圆心三行数字排不下，光带糊成一片。带一薄，孔就大了，数照样放得下。

## 写在最后

这枚环的每条规矩背后都是一次实测翻车：对账飘 0.1 GB、每秒 85 次重画、芥末色的光。SwiftUI 给了很低的起笔成本，但「每帧各段之和等于整盘」「静得下来才能测」这些约束，得自己立。

环形图的完整实现都在 [`Sources/DiskCleaner/Theme/Components.swift`](../../Sources/DiskCleaner/Theme/Components.swift) 的 `SweepRing`。如果这篇文章帮到了你，[给仓库一颗 ⭐](https://github.com/DreamOfXM/diskwise) 是对独立开发者最大的鼓励。
